# Personal Portfolio Website

A fully responsive personal portfolio built with HTML, CSS, and JavaScript — showcasing my background, skills, and projects.

**Live site:** https://pari767.github.io/portfolio-website/

## About

This portfolio introduces me as a B.E. Information Science & Engineering student (RNS Institute of Technology, 2023–2027), currently pursuing the VTU Honours Program, with hands-on experience building web applications and AI-based projects.

## Sections

- **Hero** — Name, role, and a call-to-action button
- **About** — Background, education, and a short bio
- **Skills** — HTML, CSS, JavaScript, Java, Python, and SQL, shown as animated progress bars
- **Projects** — GreenKarma and NiftyMind, with links to GitHub and live demos
- **Contact** — A form with client-side JavaScript validation (name, email, message)
- **Footer** — Links to LinkedIn, GitHub, and WhatsApp

## Built With

- **HTML5** — semantic page structure
- **CSS3** — Flexbox, Grid, custom properties, responsive design
- **JavaScript** — form validation, smooth scrolling, scroll-triggered animations, typing effect, and a light/dark theme toggle

## Features

- Fully responsive layout (desktop, tablet, mobile)
- Light/dark ("day/night") theme toggle
- Animated typing effect in the hero section
- Scroll-reveal animations for sections
- Animated skill progress bars
- Client-side form validation with inline error messages
- Sticky, collapsible navigation bar

## Running Locally

This is a static site with no build step or dependencies.

1. Clone the repository:
   ```bash
   git clone https://github.com/pari767/portfolio-website.git
   ```
2. Open `index.html` directly in your browser, or serve it locally:
   ```bash
   cd portfolio-website
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000` in your browser.
